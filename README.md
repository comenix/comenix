# Comenix

**Steward** of the [Luminaries digital universe](https://github.com/comenix/luminaries) as an open ecosystem — and **a Home Planet** in that universe.

Comenix provides the **base capabilities** independent brands build on. Independent brands add their own capabilities and **sell their own products** — each on its own domain.

## What Comenix provides

One account across brands · market-fit checkout · one story on every screen · seats and domains · delivery with protection · storage · secure integrations · one Dashboard to configure them — **Constellation · Presentation · Chariot · Traveler · Stations · Security · Storage · Bridge · Dashboard**.
